# ZELOSBIA Trading and Sourcing

This repository contains the static website for ZELOSBIA Trading and Sourcing.

Quick notes:
- The site is static HTML/CSS/JS and can be hosted on GitHub Pages, Netlify, Vercel, or any static host.
- To publish on GitHub Pages: Repo → Settings → Pages → Select branch "main" and folder "/ (root)" → Save.

Security hardening added:
- A conservative Content-Security-Policy meta tag has been added to HTML files to restrict allowed script/style/font sources.
- Referrer policy and basic Open Graph meta tags have been added.

Files added:
- sitemap.xml — sitemap for indexing
- robots.txt — allows crawling and points to sitemap

If you have a custom domain and want me to add a CNAME file, tell me the domain and I will add it.
